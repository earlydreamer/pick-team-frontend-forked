# 90. Open Questions — 논의 안건 집계

> **✅ 2026-07-04 일괄 결정**: 사용자 승인으로 §1(통합 A~G)·§2(P0)·§3(P1)·§4(P2)의 **전 항목이 각 추천안대로 확정**되었다. 각 원 문서 §8 상단에 결정 배너를 역기입했다.
> **잔존 오픈 항목은 §5(V — 검증·측정 과제) 4건뿐**: 15-D4(LiveKit 부하 테스트), 16-D1(웹푸시 채택 — 파일럿 후), 스펙 Q2(매칭 가중치 튜닝 — 파일럿), 스펙 Q1(강사 수요 인터뷰). 이들은 결정이 아니라 실험이며, 명시된 시점에 수행한다.
> 이하 표는 결정 기록으로 보존한다. 이후 결정을 뒤집을 경우 이 문서와 원 문서 §8에 변경 이력을 남긴다.

> 문서 10~17과 골격 문서(01·02)의 모든 ⚠️ 항목을 모아 **중복을 통합하고 우선순위를 매긴** 리뷰용 문서.
> 각 안건의 상세 맥락은 원 문서의 해당 ID 절을 참조. 여기서 결정되면 원 문서에 결정 내용을 역기입하고 이 문서에서 상태를 갱신한다.
>
> 원 항목 총 55건 → 중복 통합 후 **안건 44건** (통합 7건 포함).
> 우선순위: **P0** = M2(팀 빌딩) 설계 확정 전 결정 필수 / **P1** = 해당 에픽 착수 전 / **P2** = 구현 중 결정 가능(추천안 디폴트 수용 가능) / **V** = 결정이 아닌 검증·측정 과제.

## 리뷰 진행 방법 제안

1. **P0 5+2건부터**: 통합 A·B와 P0 5건은 팀 빌딩 상세 설계의 전제라 이것만 정해지면 M2 스펙이 흔들리지 않는다.
2. P1은 에픽 착수 시점마다 해당 묶음만 확인.
3. P2는 추천안을 디폴트로 수용하고, 반대할 항목만 표시하는 방식이 효율적.
4. 결정된 항목은 원 문서 §8 표에 "✅ 결정: (내용, 날짜)"로 역기입.
